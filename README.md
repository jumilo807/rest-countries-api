# REST Countries API con cambio de tema de color

Solución al reto [REST Countries API with color theme switcher](https://www.frontendmentor.io/challenges/rest-countries-api-with-color-theme-switcher-5cacc469fec04111f7b848ca) de Frontend Mentor.

## Enlaces

- **Sitio en vivo:** https://jumilo807.github.io/rest-countries-api/
- **Código fuente:** https://github.com/jumilo807/rest-countries-api

## Funcionalidades

- Ver todos los países obtenidos de la API REST Countries (v5)
- Buscar un país por nombre (sin importar tildes ni mayúsculas)
- Filtrar países por región
- Ver el detalle de un país al hacer clic en su tarjeta
- Navegar a los países fronterizos desde la vista de detalle
- Cambiar entre modo claro y oscuro (se recuerda la preferencia)
- Diseño adaptable a móvil y escritorio

## Tecnologías

- HTML5 semántico
- CSS3 (variables, Grid, Flexbox, media queries) — tipografía Nunito Sans y paleta de la guía de estilo del reto
- JavaScript (ES6+, `fetch`, `async/await`, `localStorage`)
- [REST Countries API v5](https://restcountries.com/docs/countries)

## Cómo ejecutarlo

1. Clona el repositorio.
2. Abre la carpeta con VS Code y usa la extensión **Live Server** (la API bloquea peticiones hechas desde `file://`).
3. En restcountries.com → *API Keys*, agrega `localhost`, `127.0.0.1` y `jumilo807.github.io` como orígenes permitidos de tu key.
